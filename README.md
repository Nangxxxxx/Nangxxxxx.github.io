# Renxiang Wang — Personal Website

A lightweight academic personal website published with GitHub Pages.

## Add your photo

Upload a portrait named `profile.jpg` to the repository root. The site will use it automatically in the reserved photo area. A vertical 4:5 image works best.

## Update the website

Edit `index.html` for content and `styles.css` for appearance. Changes published to the `main` branch will update the website.
